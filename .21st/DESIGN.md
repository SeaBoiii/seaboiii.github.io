# Compute Core design context — second edition

The user approved a stronger product-led revision: generous editorial identity, one continuous expanding compute module, coloured project collections, four researched case studies, and optional music. Nothing's Headphone (1) Pro page informs material detail, scale, spacing and section rhythm; the portfolio retains its own geometry, typography and content.

Page order: identity → expanding core → selected work → AMD collection → journey → toolkit → playground → about → contact. Use warm paper and graphite as the base, vermilion `#C7382A` for the AMD collection, cobalt `#284BE8` for the playground, and sparse lime `#C3E85B` signals. Instrument Sans and IBM Plex Mono remain self-hosted.

The core belongs to a single local sticky section. Its camera angle and position stay stable as native scroll lifts the cover, separates layers and reveals connections. It leaves with its own section before the project stories. Navigation never changes its pose. Compact static, reduced-motion and short-height layouts preserve the diagram and HTML explanation in normal flow. There is no travelling canvas or pointer-driven rotation.

Music is a locally stored, user-initiated instrumental. Every visit begins with sound off; the file is requested only after a click. There is no audio dependency on scroll or WebGL, and no generation service is called by builds or browsers.

Canonical contract: `portfolio/docs/DESIGN_SYSTEM.md`. Factual content: `portfolio/docs/CONTENT_EVIDENCE.md`. The initial studies in `DESIGN_RESEARCH.md` and `directions.html` are historical exploration; this revision supersedes their travelling-scene and restrained-colour choices.

Use semantic DOM, native scroll, 44 px controls, visible keyboard focus, readable contrast and HTML/SVG fallbacks. Keep mobile content legible, without cursor replacement, skill ratings or decorative loading sequences. Anthropic's frontend-design and ElevenLabs' music skills support this revision; they do not add frontend dependencies.

21st catalog search required unavailable authentication. Existing 21st build/review skills remain useful, and deterministic `21st review` runs locally. No retrieved catalog component or hosted 21st generation is claimed. Rendered browser QA remains authoritative for layout and interaction.
